# Campus Lost & Found Management System

A menu-driven C programming project designed to manage found items on a college/campus environment.

## 📌 Project Overview

The Campus Lost & Found Management System allows users to register found items and manage their records efficiently.

Instead of maintaining lost and found information manually, the system provides a simple computerized way to:

- Report found items
- View all registered items
- Search for an item
- Search items by location
- Mark an item as claimed
- Delete an item record
- Store data permanently using file handling

## 🎯 Objectives

The main objectives of this project are:

1. To create a simple campus Lost & Found management system.
2. To reduce manual record keeping.
3. To make searching for found items easier.
4. To demonstrate important C programming concepts.
5. To store records permanently using file handling.

## ⚙️ Features

### 1. Report Found Item
Users can enter:

- Item name
- Category
- Found location
- Finder name
- Contact number
- Date

Each item receives an Item ID.

### 2. View All Items
Displays all currently registered found-item records.

### 3. Search Item
Users can search for an item by its name.

The search supports partial matching.
